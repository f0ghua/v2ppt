# V2PPT GUI 使用指南

## 🎬 简介

V2PPT GUI 是一个简单易用的图形界面工具，用于从视频中提取 PPT 页面并生成 PowerPoint 文件。

## 🚀 快速开始

### 启动 GUI

```bash
# 启动图形界面
python gui_main.py

# 查看版本信息
python gui_main.py --version

# 查看帮助
python gui_main.py --help
```

### 基本使用流程

1. **选择视频文件**：点击"浏览..."按钮选择要处理的视频文件
2. **设置输出目录**：选择 PPT 文件的保存位置
3. **选择处理模式**：
   - **标准模式**：平衡的处理效果，适合大多数情况
   - **保守模式**：保留更多幻灯片，适合内容变化较快的视频
   - **非常保守**：最大程度保留幻灯片，适合重要内容不能遗漏的场景
   - **自定义**：手动调整所有参数
4. **开始处理**：点击"▶️ 开始处理"按钮
5. **查看进度**：在右侧面板实时查看处理进度和日志

## ⚙️ 界面功能详解

### 输入设置区域

- **视频文件**：支持 MP4, AVI, MOV, MKV, WMV, FLV, M4V 等格式
- **输出目录**：PPT 文件的保存位置，默认为 `output/ppt`

### 处理设置区域

#### 处理模式
- **标准模式**：相似度阈值 0.8，帧间隔 5 秒
- **保守模式**：相似度阈值 0.7，帧间隔 4 秒
- **非常保守**：相似度阈值 0.6，帧间隔 3 秒，关闭内容过滤
- **自定义**：显示高级设置面板，可手动调整所有参数

#### 高级设置（自定义模式）
- **相似度阈值**：控制重复检测的严格程度（0.0-1.0）
  - 值越高，去重越严格，可能丢失相似的不同页面
  - 值越低，保留更多页面，但可能包含重复内容
- **帧间隔**：视频帧提取的时间间隔（秒）
  - 值越小，提取越频繁，处理时间越长
  - 值越大，可能错过快速切换的页面
- **跳过设置**：跳过视频开头和结尾的时间（秒）
- **处理选项**：
  - **图像增强**：提升图像质量和清晰度
  - **去除重复**：移除相似的重复图像
  - **PPT内容过滤**：只保留看起来像 PPT 的图像

#### PPT 设置
- **标题**：演示文稿标题
- **作者**：演示文稿作者
- **添加幻灯片标题**：为每张幻灯片自动添加标题

### 控制区域

- **▶️ 开始处理**：启动视频处理
- **⏹️ 停止**：停止当前处理（仅在处理中可用）
- **🔄 重置**：重置所有设置到默认值
- **❓ 帮助**：显示详细使用帮助

### 进度监控区域

- **当前步骤**：显示正在执行的处理步骤
- **进度条**：显示整体处理进度
- **时间信息**：显示已用时间和预计剩余时间
- **详细信息**：显示当前步骤的详细状态

### 日志区域

- **实时日志**：显示详细的处理日志
- **日志控制**：
  - **清空日志**：清除当前日志内容
  - **保存日志**：将日志保存到文件
  - **自动滚动**：自动滚动到最新日志

## 🎯 使用技巧

### 处理模式选择建议

1. **首次使用**：建议使用"标准模式"
2. **PPT 页面丢失**：尝试"保守模式"或"非常保守"
3. **处理时间过长**：使用"标准模式"并增加帧间隔
4. **精确控制**：使用"自定义"模式手动调整参数

### 参数调优指南

#### 相似度阈值调整
- **0.9-1.0**：非常严格，适合内容变化很大的视频
- **0.7-0.8**：标准设置，适合大多数情况
- **0.5-0.6**：宽松设置，适合内容变化较小的视频

#### 帧间隔调整
- **1-3 秒**：高频提取，适合快速切换的内容
- **5-8 秒**：标准设置，平衡效果和速度
- **10+ 秒**：低频提取，适合变化缓慢的内容

### 常见问题解决

#### 问题：生成的 PPT 缺少页面
**解决方案**：
1. 使用"保守模式"或"非常保守"
2. 降低相似度阈值（如 0.6）
3. 减少帧间隔（如 3 秒）
4. 关闭"PPT内容过滤"

#### 问题：处理时间过长
**解决方案**：
1. 增加帧间隔（如 8-10 秒）
2. 关闭"图像增强"
3. 使用"标准模式"

#### 问题：PPT 包含太多重复页面
**解决方案**：
1. 提高相似度阈值（如 0.9）
2. 确保"去除重复"已启用
3. 启用"PPT内容过滤"

## ⌨️ 快捷键

- **Ctrl+O**：选择视频文件
- **F5**：开始处理
- **Esc**：停止处理

## 📁 输出文件

- **PPT 文件**：保存在指定的输出目录
- **中间文件**：保存在 `output/frames/` 目录
- **日志文件**：保存在 `output/logs/` 目录

## 🔧 故障排除

### GUI 无法启动
1. 检查 Python 版本（需要 3.10+）
2. 确认 tkinter 可用：`python -c "import tkinter"`
3. 检查项目文件完整性

### 处理失败
1. 查看日志区域的错误信息
2. 确认视频文件格式支持
3. 检查输出目录权限
4. 尝试使用较小的视频文件测试

### 性能问题
1. 关闭不必要的处理选项
2. 增加帧间隔
3. 使用 SSD 存储
4. 确保有足够的磁盘空间

## 📞 技术支持

如果遇到问题，请：
1. 查看日志文件获取详细错误信息
2. 尝试使用命令行版本：`python improved_processing.py --help`
3. 检查项目文档和 README 文件
